# Dalmondeor Primary website

A responsive, accessible one-page school website inspired by the playful Kidzu school theme and adapted to Dalmondeor Primary's blue-and-yellow identity.

## Preview locally

Run any static web server in this folder, for example:

```powershell
python -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.

## Project files

- `index.html` — page content and structure
- `styles.css` — responsive layout and visual system
- `script.js` — mobile navigation, phase tabs, FAQs, carousel, reveal effects and counters
- `assets/dalmondeor-logo-v2.png` — supplied school crest
- `assets/hero-learners-uniform.png` — supplied learner artwork used in the hero
- `assets/hero-learners.png` — original fictional learner cutout retained as a backup
- `assets/learning-together.png` — fictional AI-generated classroom scene
- `assets/hockey-together.png` — fictional AI-generated school-sport scene
- `assets/sports-cricket.png` — supplied cricket photograph used in the rotating sports gallery

The phone number, area, Facebook link and school description were taken from the public Dalmondeor Primary Facebook page. The learner and teacher imagery depicts fictional people created specifically for this concept.
